Программы для Windows подписывают, чтобы Windows и антивирусы видели, кто их выпустил и что по дороге их никто не изменил. AimOdometer будет подписываться бесплатно по программе SignPath Foundation для проектов с открытым кодом.

Free code signing provided by SignPath.io, certificate by SignPath Foundation. (Бесплатная подпись кода от SignPath.io, сертификат от SignPath Foundation.)

Что подписывается

  • Программы AimOdometer: AimOdometer.App.exe (окно), AimOdometer.Tracker.exe (счётчик) и собственные библиотеки AimOdometer, а также установщик AimOdometerApp-win-Setup.exe.
  • Только файлы, собранные GitHub Actions из отмеченного версией коммита открытого репозитория zegolka-dev/AimOdometer. То, что собрано на чьём-то компьютере, не подписывается никогда.
  • Чужие файлы, которые идут вместе с программой (среда .NET, SQLite, загрузчик WebView2, MapLibre), сохраняют подписи своих авторов или остаются без подписи; сертификат AimOdometer для них не используется.

Все участники входят в GitHub и SignPath с двухфакторной защитой. Изменения от других людей приходят как pull request и проверяются до слияния.

Конфиденциальность

Программа ничего не передаёт в другие сетевые системы, если пользователь сам этого не попросил, с одним исключением, которое включено по умолчанию и отключается: она спрашивает у GitHub, есть ли новая версия. Всё остальное (карта, вход через Steam и таблицы лидеров) работает только после того, как пользователь это включит. Подробности в политике приватности.

Если что-то не так

Если тебе кажется, что подписанный файл AimOdometer делает то, чего не должен, напиши issue на GitHub.
