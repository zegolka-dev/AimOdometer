Windows programs are signed so that Windows and antivirus software can tell who published them and that nobody changed them on the way. AimOdometer is going to be signed for free through the SignPath Foundation program for open-source projects.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

  • The programs of AimOdometer: AimOdometer.App.exe (the window), AimOdometer.Tracker.exe (the counter) and AimOdometer's own libraries, plus the installer AimOdometerApp-win-Setup.exe.
  • Only files built by GitHub Actions from a tagged commit of the public repository zegolka-dev/AimOdometer. Nothing built on a personal computer is ever signed.
  • Third-party files that ship with the app (the .NET runtime, SQLite, WebView2 loader, MapLibre) keep the signatures of their authors or stay unsigned; AimOdometer's certificate is not used for them.

Privacy

This program will not transfer any information to other networked systems unless the user asks for it, with one exception that is on by default and can be switched off: it asks GitHub whether a newer version exists. Everything else (the map, Steam sign-in and leaderboards) happens only when the user turns it on. The details are in the privacy policy.

Reporting a problem

If you believe a signed AimOdometer file does something it should not, open an issue on GitHub.
