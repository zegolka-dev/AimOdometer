Anti-cheat safety

Anti-cheat systems look for programs that change the game, read its memory or draw over it. AimOdometer does none of that. It works like the software that comes with gaming mice.

How AimOdometer works

  • Mouse: Windows Raw Input in background mode (RIDEV_INPUTSINK), the same public API games and mouse software use. It only receives a copy of what the mouse sends; it cannot change or block input.
  • Which game: it asks Windows which window is in front and reads the path of that program's .exe. Nothing else about the game.
  • Notifications: achievements wait until you leave a full-screen game.
  • Games that run as administrator (Genshin Impact, Honkai: Star Rail, Zenless Zone Zero): Windows hides the mouse from normal programs while such a window is in front. The optional setting “Count games that run as administrator” starts the tracker with administrator rights through Windows Task Scheduler; it still only reads the mouse.

What it never does

  • No hooks (no SetWindowsHookEx), no DLL injection, no drivers.
  • Never opens game processes, never reads or writes their memory.
  • No overlay, no drawing over games, no input simulation.
  • Never reads the keyboard.

Test results

Each game: the tracker running before launch, at least 30 minutes (two matches for FACEIT / Vanguard), then: no anti-cheat warning or kick, distance recorded for the game, no FPS change beyond noise.
