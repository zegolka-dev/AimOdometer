# Privacy / Приватность

The full policy is on the website: [English](https://zegolka-dev.github.io/AimOdometer/privacy.html) ·
[Русский](https://zegolka-dev.github.io/AimOdometer/ru/privacy.html) (source: `site/content/privacy.*.html`).

## In short

- Statistics (mouse distance, clicks, wheel, time in motion, which program was in front) stay on your PC in
  `%LOCALAPPDATA%\AimOdometer`. The keyboard, the screen, window titles and game memory are never read.
- The background tracker never uses the internet. The window contacts GitHub to check for updates (can be switched
  off), map services only after you allow the Map tab, and the AimOdometer cloud (Supabase, EU) only after you sign in
  through Steam: then daily totals per game and hashed mouse (with the DPI they were measured at), your public Steam profile and a random PC id are synced.
- Friends see you by default, the world leaderboard is opt-in. Leaderboards show the DPI behind your distance and
  fastest flick, and badges such as "Clown" for distance inflated by a DPI set far too low. Delete the cloud account or the local statistics from
  Settings at any time. No analytics, no telemetry, no ads.

## Коротко

- Статистика (пробег мыши, клики, колесо, время в движении, какая программа была на переднем плане) хранится на твоём
  ПК в `%LOCALAPPDATA%\AimOdometer`. Клавиатура, экран, заголовки окон и память игр не читаются никогда.
- Фоновый трекер в интернет не ходит. Окно обращается к GitHub за обновлениями (отключается), к картографическим
  сервисам - только после разрешения на вкладке «Карта», к облаку AimOdometer (Supabase, ЕС) - только после входа через
  Steam: тогда синхронизируются итоги за день по играм и хэшам мышей, открытый профиль Steam и случайный id ПК.
- Друзья видят тебя по умолчанию, мировой рейтинг - по желанию. Аккаунт в облаке и статистику на ПК можно удалить в
  Настройках в любой момент. Ни аналитики, ни телеметрии, ни рекламы.
