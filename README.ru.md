## Зачем ещё один одометр мыши?

Классические программы (Mousotron, Mouse Odometer и др.) считают путь **курсора** в пикселях экрана. В шутерах вроде CS2, Apex или Valorant курсор зажат в центре, а игра читает «сырой» ввод — поэтому такие программы почти ничего не видят.

AimOdometer читает **сырые отсчёты сенсора** через Windows Raw Input и переводит их в сантиметры по DPI твоей мыши:

```
сантиметры = отсчёты / DPI × 2.54
```

## Принципы

- **Лёгкий фоновый процесс.** Крошечный NativeAOT-трекер, работает только по событиям. Цель: ≤ 15 МБ памяти, ~0% CPU в простое.
- **Безопасно для античитов.** Никаких хуков, инъекций, оверлеев и чтения памяти игр. Только пассивный Raw Input и имя активного приложения.
- **Приватно.** Клавиатура не читается вообще. Без входа через Steam — никаких сетевых запросов, кроме отключаемой проверки обновлений.

## Сборка из исходников

Нужно: Windows 10 22H2+ / 11 x64, [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0). Для NativeAOT-публикации трекера — ещё Visual Studio Build Tools с компонентом C++.

```bash
dotnet build -c Release
dotnet test -c Release
```
