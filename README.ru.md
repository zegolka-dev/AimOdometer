## Скачать

Windows 10 22H2+ / Windows 11, 64-бит. Последняя версия — в [Releases](https://github.com/zegolka-dev/AimOdometer/releases):

- **`AimOdometerApp-win-Setup.exe`** — ставится для текущего пользователя (без прав администратора), добавляет ярлыки в
  «Пуск» и на рабочий стол и запускается вместе с Windows.
- **`AimOdometerApp-win-Portable.zip`** — распакуй в любую папку и запусти `AimOdometer.exe`.

Обе версии обновляются сами: при открытии окна (и раз в час, пока оно открыто) AimOdometer ищет новый релиз,
устанавливает его и перезапускается. Отключается в Настройках. .NET уже внутри, больше ничего ставить не нужно.

Сборки пока без цифровой подписи, поэтому Windows может показать «Windows защитила ваш компьютер»: нажми
**Подробнее → Выполнить в любом случае**.

## Зачем ещё один одометр мыши?

Классические программы (Mousotron, Mouse Odometer и др.) считают путь **курсора** в пикселях экрана. В шутерах вроде CS2, Apex или Valorant курсор зажат в центре, а игра читает «сырой» ввод — поэтому такие программы почти ничего не видят.

AimOdometer читает **сырые отсчёты сенсора** через Windows Raw Input и переводит их в сантиметры по DPI твоей мыши:

```
сантиметры = отсчёты / DPI × 2.54
```

## Принципы

- **Лёгкий фоновый процесс.** Крошечный NativeAOT-трекер, работает только по событиям. Цель: ≤ 15 МБ памяти, ~0% CPU в простое.
- **Безопасно для античитов.** Никаких хуков, инъекций, оверлеев и чтения памяти игр. Только пассивный Raw Input и имя активного приложения.
- **Приватно.** Клавиатура не читается вообще. Вход через Steam — по желанию: он синхронизирует итоги за день по играм и мышам с облаком AimOdometer, чтобы видеть все свои ПК вместе. Без входа — никаких сетевых запросов, кроме отключаемой проверки обновлений и вкладки «Карта», которая загружается только после твоего разрешения на ней самой (фрагменты карты с OpenFreeMap, поиск городов через Nominatim, пешие маршруты через OSRM; они видят твой IP-адрес и искомые города — больше ничего).

## Известные ограничения

- В Windows 11 фоновые программы получают движение мыши склеенным до ~125 отчётов в секунду. Прямые движения
  считаются точно, но при активном аиме трекер записывает примерно на 2 % меньше пути, чем мышь прошла на самом деле
  (замер: −2.3 %). Подробности — в [docs/PERFORMANCE.md](docs/PERFORMANCE.md).
- Если переключаешь DPI кнопкой на мыши, AimOdometer этого не видит: укажи новый DPI в меню трея.

## Сборка из исходников

Нужно: Windows 10 22H2+ / 11 x64, [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0). Для NativeAOT-публикации трекера — ещё Visual Studio Build Tools с компонентом C++.

```bash
dotnet build -c Release
dotnet test -c Release
```
